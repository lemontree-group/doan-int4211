# Đồ án cuối kỳ INT4211

## Đề tài 3: Hệ thống đặt suất ăn công nghiệp cho khu công nghiệp

### 1. Mục tiêu

Xây dựng hệ thống hỗ trợ quản lý nhà máy, thực đơn, đăng ký suất ăn, chốt số lượng suất, tổng hợp nguyên liệu, đánh giá chất lượng bữa ăn và báo cáo.

### 2. Công nghệ dự kiến theo yêu cầu môn học

- **Android Admin:** Android Studio, Java, XML.
- **Flutter Client:** Flutter, Dart.
- **Backend:** Node.js, Express.
- **Cơ sở dữ liệu:** PostgreSQL trên Supabase.
- **Lưu trữ hình ảnh:** Supabase Storage.
- **Triển khai Backend:** Render.
- **Xác thực:** JWT và bcrypt.
